01 — FOUNDATION

What is Flexbox?

Flexbox is a CSS layout system designed to arrange elements in one dimension: either a row or a column.

01

Flex Container

The parent element that receives display: flex.

display: flex;
02

Flex Items

The direct children of a Flex Container become Flex Items.

flex items
03

One Dimension

Flexbox works mainly on one axis at a time: horizontal or vertical.

row / column
Important: Flexbox is excellent for one-dimensional layouts. CSS Grid is generally better when you need two-dimensional layouts.

Main Axis

07 — WRAPPING

08 — FLEX ITEMS

Controlling Flex Items

Tailwind also gives us utilities to control individual Flex Items.

flex-1

Allows an item to grow and fill available space.

flex-1

grow

Allows a Flex Item to grow when extra space is available.

grow

shrink

Allows an item to shrink when necessary.

shrink

basis

Defines the initial size of a Flex Item.

basis-1/2

order

Changes the visual order of Flex Items.

order-1

self

Controls alignment of one individual item.

self-center
